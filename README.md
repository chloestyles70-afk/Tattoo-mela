# TATTOO

A mobile-first interactive story made for Mela.

## Current build
- Sweet opening screen for Mela
- Begin button starts the story and attempts to play background music
- Chapters 01–05
- Final letter
- Open When section
- Next / Back / Replay controls
- Music toggle
- Responsive mobile-first design
- Easy song replacement: place the chosen file at `assets/song.mp3`
- Memory cards ready for photos/videos

## Planned final pass
Replace the placeholder chapter copy with the locked personal story, insert the chosen photos/videos, and add the final song.

## Run
Open `index.html` in a browser, or serve the folder with a simple local web server. Browsers may block autoplay until the Begin button is pressed; the app starts music from that user action.
